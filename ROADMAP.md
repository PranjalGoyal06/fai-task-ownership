## Required experiments and acceptance checks

| Commitment | Evidence for the final report |
| --- | --- |
| **RQ1 — Cost of misalignment** | Run B1–B4 on shared task draws. Sweep the misaligned fraction $\phi$ for both deflection and acquisition, including the aligned control. Report welfare, regret, miss loss $\Delta V$, excess assignment cost $\Delta C$ and efficiency $\eta$ where oracle welfare is positive. Check the oracle order under its stated assumptions and the stale-router cost gap. Study unmediated claiming separately through the deflection mixed equilibrium and the acquisition entry threshold, including a numerical comparison to the planner's threshold. |
| **RQ2 — Recovery under a budget** | Compare B2, scoring only, audits only and both with credit off. Search a declared grid of $(\lambda,\alpha)$ for the least regret within each budget. Show gross regret recovered versus B2 and net recovery after centered score and audit costs. Check when cheap reports lose information, the direction and size of clipped Brier shading under local linearity, and audit deterrence across degree, detection and penalty settings. Report regimes where recovery pays off and where it falls short, and show a crossover only if observed. |
| **RQ3 — Coalition ownership** | Vary $k$ under both resolution rules. Compare credit off, equal split and Shapley with scoring and audit settings held fixed. Check $\omega^k$ and $1-(1-\omega)^k$ in a controlled independent-identification run, then measure coverage and padding under strategic reports. Report both mean extra assignees and the share of tasks with any extra assignees. |
| **E0 — Synthetic simulator** | Include single-owner, conjunctive and disjunctive tasks. Sweep agent count, coalition size, graph density, incentive prevalence and signed strength, scoring and audit settings, missing evidence, stale descriptions and calibration. Use the draft's Gaussian evidence with a graph-neighbour term and an independent benchmark with that term set to zero. Measure binned ECE across logit-slope distortions. Use one-factor sweeps and focused interactions for the RQs. Compare closed forms to simulation within sampling uncertainty and document discrepancies. |
| **E1 — Grounded issue-to-module test** | Run the shared mechanisms, B1–B4 and ablations on held-out later issues from at least one open-source repo. Use the resolving patch for proxy owner labels, the pre-fix import graph, earlier issues for training per-module text classifiers, and cutoff-era module docs for B1. Inject signed incentives and compare method ordering with E0. Report held-out sample counts, $k$ distribution, calibration and uncertainty. |

The headline figures are regret versus $\phi$ by incentive sign, predicted versus observed shading, coverage versus $k$ by resolution rule, and regret versus ECE. Add a budget–regret frontier and a padding comparison. Log escalation hops and modeled message counts. If reporting tokens, use a declared counting convention on real text and label synthetic counts as estimates.

## Decisions to settle on 11 November

- **Oracle and baselines.** B4 sees all evidence, with ground truth reserved for outcome evaluation. For conjunctive tasks use exact set selection on small instances, with the product objective only when its independence assumption holds. For fixed-size or graph-coupled owner sets, compute joint posterior coverage numerically. For escalation compare expected welfare over ordered prefixes with the same stop-on-success feedback, and verify the full-search $\pi_i^\star/c_i$ order in the single-owner and independent disjunctive cases. Fix tie-breaking, zero-cost ordering, the empty-set convention and B3's vote rule using only each agent's local evidence and public priors. Keep B3 single-winner and explain its coverage limit for $k>1$. On E1, fit a pooled-evidence B4 benchmark using training data only and label it an estimated oracle.
- **Reporting and audits.** Use a discrete strategy per local evidence bin and private type, with a 0.05 report grid as the starting point. Estimate interim expected utility conditional on the agent's information. Keep score-only shading distinct from withholding or misrepresenting a genuine payload. The proposed audit rule penalizes contradicted payloads and replaces the report for selection with a verified estimate, or the public prior if the check establishes only a contradiction. Score the submitted probability after independent ex-post reveal, including failed assignments in simulation and replay. Verify the deterrence threshold in the case where detection removes the manipulation gain. Record profitable unilateral-deviation residuals, cycle or iteration-limit outcomes and sensitivity to initialization. Label unresolved runs separately from approximate equilibria. State the subjective-belief convention for miscalibrated agents.
- **Credit and costs.** Calculate Shapley on the assigned set. A resolved conjunctive task pays $R/k$ to each required owner. A resolved disjunctive task splits $R$ among the required owners actually assigned. Check that unassigned agents and assigned non-owners receive zero Shapley credit. Use the paper's centered scoring and audit cost for the RQ2 budget. Log credit and fines separately and keep assignment costs in welfare.
- **Real-data gate.** Start with a filtered subset of full SWE-bench. Its issue text, base commits and patches support the proposed pipeline. Start with roughly 5–15 module agents. Combine issue text with features from each agent's own module at the pre-fix commit. Freeze the repo selection, module map, time split and exclusions after the pilot. If the first repository has too few usable multi-module fixes, switch to another full SWE-bench repository or a small set of verified public issue–patch pairs by 12 Nov. Keep patch contents and later repository information out of features. [SWE-bench dataset](https://huggingface.co/datasets/SWE-bench/SWE-bench)
- **Run budget and reproducibility.** Tentatively read the draft's target as 10,000 evaluation tasks per final synthetic configuration across 20 independent seeds. Record the interpretation and confirm it against the pilot. Reuse task draws across methods, cache posteriors where practical, and use paired 95% bootstrap intervals. Keep expensive exact checks on selected small cases. The run manifest records revision, config, data split, seeds, convergence diagnostics and the command that regenerates the results.

## If the schedule slips

Run the synthetic core and the data feasibility pilot in parallel so E1 data problems surface early. If the 15 Nov integration gate slips, drop Myerson credit, the incident-routing implementation and extra datasets first. Thin interior sweep points or extra interactions next while retaining every promised baseline, ablation, benchmark and research question. If a required result is incomplete, record the exact gap and use the verification buffer for that rerun. Treat null findings, weak audit regimes and solver non-convergence as results with their conditions attached.
